把你的开场音效放这个目录（config.jsonc 里 "sfx": "auto" 会自动用「文件名排序第一个」）：

  音频：mp3 / wav / ogg / m4a / aac / flac / opus
  视频：mp4 / mov / m4v / webm（只取里面的音轨 —— 抖音等平台保存下来的 mp4 可以直接用）

目录里现在有两首（都是本地合成的原创音，可用可删）：
  00-国风开场.wav   古琴拨弦 + 大鼓 + 磬 + 剑鸣（3.6s，默认会用这首）
  开天门.wav        低频轰鸣 + 剑气呼啸 + 光爆「叮」（3.0s）

—— 换成你自己的歌（例如《知我》副歌）——

1. 把文件放进来，然后在 config.jsonc 里写文件名，例如：
     "sfx": "知我.mp3"
2. 用播放器看副歌从第几秒开始，换算成毫秒填进 config.jsonc：
     "sfxStartMs": 62000        // 副歌 1 分 02 秒开始 → 62000
     "sfxDurationMs": 8000      // 播 8 秒后淡出；填 0 = 跟动画一起结束
     "sfxFadeOutMs": 1200       // 淡出 1.2 秒，避免硬切
3. 想让动画陪着音乐一起变长：把 "minDurationMs" 调成和副歌时长相当（例如 8000）

注：歌曲是有版权的，请用你自己合法获取的文件；插件只做本地播放，不联网。
